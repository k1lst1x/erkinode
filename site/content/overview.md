# Documentation

Erkinode is a free, open-source desktop workspace for SSH, SFTP, and local terminals. Your hosts and credentials are stored on your device; connections go directly to the servers you choose.

## Start here

1. [Install the desktop app](./installation/).
2. [Save your first host and connect](./connections/).
3. [Open a local terminal](./terminal/), or [move files with SFTP](./files/).

You do not need an Erkinode account or subscription. You do need access credentials for any remote server you connect to. A browser cannot use the desktop app's direct SSH connections: download and run the application.

## What is available

- Saved hosts, groups, tags, favorites, search, and grid/list layouts.
- SSH passwords, private keys, SSH agent integration, and keyboard-interactive prompts.
- Host fingerprint verification, jump hosts, and local port forwarding.
- Local shells alongside SSH tabs, split panes, terminal search, and saved command snippets.
- SFTP file browsing, a text editor, uploads/downloads, and transfer progress.
- English, Russian, and Kazakh interfaces.
- Encrypted local credentials and password-protected portable backups.

## Beta status

Erkinode is in active development. Full Termius feature parity is not claimed. Cloud synchronization, shared team vaults, mobile apps, and automatic application updates are not implemented. Download a new release to update the app.

See [platform support](./platforms/) and [validation](./validation/) for what has actually been tested. An available build is not a claim that every feature has been verified on every OS.
